Arduino 06

Simuaciones en Tinkercad

Objetivos de esta clase

Diagramas en Tinkercad

Iniciar sesión

Como vimos en una de las primeras clases sobre Arduino, Tinkercad nos permite, entre otras funciones que posee, simular circuitos. Ingresmos a Tinkercad acá. Para crear un circuito en Tinkercad debemos tener una cuenta. Un método sencillo de autenticación es usar una cuenta de Google, aunque podemos crear una con nuestro correo.

Crear un diagrama

Para cear un diagrama vamos a la sección Diseños y luego a Circuitos. Ali podemos darle al boton “crear” seleccionando “circuitos” y comenzar.

La barra lateral nos nuestra un listado de componentes y sus nombres. También tenemos un cuadro de búsqueda que nos permitirá agilizar este proceso.

Componentes

Una vez que elegimos un componente y lo arrastramos al tablero principal podremos elegir sus características

Código

En la sección código podremos elegir entre varias formas de interacción. Nosotros seleccionaremos la versión texto que nos da una visual similar al Arduino IDE con opción a escribir en el lenguaje de Arduino.

Simulación

Una vez que hemos hecho una conexión y hemos agregado el codigo corresopndiente podemos iniciar nuestra simulación.

Limitaciones (sensores)

Los sensores de entorno ya sean fotoresistencias, sensores de distancia por ultrasonido, de temperatura, etc. no están realmente conectados a ningún entorno real en tintkercad sino que permiten a través de la interacción del usuario con controles deslizantes emular lo que el sensor estaría viendo. Esto pone una limitación a que tanto de una disposición experimental puede simularse ya que si bien es posible mover un deslizador para que, por ejemplo, el HCSR-04 mida una distancia, este valor no puede ser controlado por el usuario de manera que efectivamente se comporte como un objeto de la realidad. Traten de imaginarse moviendo un puntito en pantalla con una aceleración igual a \(g\). No es factible. Como en muchas otras circunstancias, los sucedáneos de código tiene problemas para abarcar la complejidad del mundo de las cosas reales.

Actividad (pre-parcial)

Reutilizaremos parte del código de calibración del LDR para comenzar

const int LDR_PIN = A0;
const int LED_PIN = 9;

void setup() {
  Serial.begin(9600);
  pinMode(LED_PIN, OUTPUT);
  Serial.println("CALIBRACION_INICIADA");
}

void loop() {
  // Calibración: variar intensidad LED y medir respuesta LDR
  // Se puede achicar el paso del for pwm y tener mas puntos
  for (int pwm = 0; pwm <= 255; pwm += 10) {
    analogWrite(LED_PIN, pwm);
    delay(800);  // Tiempo para estabilización
    
    int valor_analogico = analogRead(LDR_PIN);
    float voltaje = valor_analogico * (5.0 / 1023.0);
    
    // Enviar datos: PWM, valor analógico, voltaje
    Serial.print("CAL,");
    Serial.print(pwm);
    Serial.print(",");
    Serial.print(valor_analogico);
    Serial.print(",");
    Serial.println(voltaje, 4);
  }
  
  Serial.println("CALIBRACION_TERMINADA");
  while(1);  // Detener después de la calibración
}

Con este código deberán en Tinkercad

  1. Conectar los componentes necesarios, correr la simulación e Interactuar con el deslizador del para obtener diferentes valores de lectura en la “calibración”
  2. Reformular el código y las conexiones para que el LED se encienda cuando el LDR mida un valor por debajo de un umbral y se apague cuando lo supere.
