ARDUINO_PORT = 'COM3'
BAUD_RATE = 115200
LONGITUD_PENDULO = 0.5  # metros (ajustar)

print("Comenzando adquisición... Presione Ctrl+C para detener")

try:

                t_ms, d = data.split(',')
                tiempos.append(float(t_ms))

            except:
                continue

except KeyboardInterrupt:

    # Convertir a arrays y ajustar tiempos
    tiempos = np.array(tiempos)
    distancias = np.array(distancias)
    tiempos_s = (tiempos - tiempos[0]) / 1000.0  # Segundos desde inicio

2.3.1 Explicación del Procesamiento en Python

2.3.1.1 Detección de Puntos de Equilibrio

  • Usamos scipy.signal.find_peaks sobre el negativo de las distancias para detectar mínimos:

    min_indices = find_peaks(-distancias, ...)

  • Parámetros clave:

    • height: Rango de distancias válidas
    • distance: Mínimas muestras entre mínimos (evita detecciones múltiples)
    • prominence: Importancia del mínimo (ajustar según ruido)

2.3.1.2 Cálculo de Periodos

  • Calculamos diferencias entre tiempos consecutivos de mínimos:
    \[ T_i = t_{\text{min}}^{i+1} - t_{\text{min}}^i \]

    periodos = np.diff(tiempos_minimos)

2.3.1.3 Análisis Físico

  • Periodo teórico:
    \[ T_{\text{teórico}} = 2\pi \sqrt{\frac{L}{g}} \]
  • Error relativo:
    \[ \epsilon = \frac{|T_{\text{medido}} - T_{\text{teórico}}|}{T_{\text{teórico}}} \times 100\% \]

Tu observación es totalmente válida y revela un punto crucial en la interpretación de los datos. Permíteme explicar y corregir este aspecto:

2.4.2 El Problema Fundamental: Semi-Períodos vs. Períodos Completos

En un movimiento pendular, cuando el sensor detecta cada pasada por el punto de equilibrio (posición mínima), está registrando dos eventos por oscilación completa: 1. Pasada en dirección A (ej: izquierda → derecha) 2. Pasada en dirección B (ej: derecha → izquierda)

La diferencia entre dos mínimos consecutivos corresponde a medio período, no a un período completo. Esto se debe a: \[ T_{\text{completo}} = t_{n+2} - t_n \] \[ \Delta t_{\text{consecutivo}} = t_{n+1} - t_n = \frac{T}{2} \]

2.4.3 Corrección del Código Python

Modifiquemos el procesamiento para calcular períodos completos correctamente:

# Después de detectar los índices de mínimos
tiempos_minimos = tiempos_s[min_indices]  # Tiempos de cada pasada por el equilibrio

# Calcular períodos COMPLETOS (entre pasadas equivalentes)
periodos_completos = []
for i in range(2, len(tiempos_minimos)):
    if i % 2 == 0:  # Considerar solo mínimos en la misma dirección
        T_completo = tiempos_minimos[i] - tiempos_minimos[i-2]
        periodos_completos.append(T_completo)

# Alternativa vectorizada (si hay número par de mínimos)
# periodos_completos = tiempos_minimos[2::2] - tiempos_minimos[:-2:2]

  if (distancia < DISTANCIA_UMBRAL) {

  Serial.print(millis());

  Serial.println(distancia, 1);  // 1 decimal

  delay(15);  // ~66 muestras/segundo
}

2.4.13 Explicación de las Mejoras

  1. Indicador LED integrado:

    • El LED en el pin 13 se enciende cuando la distancia es menor que DISTANCIA_UMBRAL
    • Esto proporciona retroalimentación visual inmediata durante el experimento
    • El umbral es configurable (30 cm en este caso)

  2. Cálculo correcto de períodos completos:

    for i in range(2, len(tiempos_minimos)):
    if i % 2 == 0:  # Índices pares: misma dirección
        periodo = tiempos_minimos[i] - tiempos_minimos[i-2]
        periodos.append(periodo)
    • Consideramos solo mínimos alternados para obtener períodos completos
    • Por ejemplo: T1 = t2 - t0, T2 = t4 - t2, etc.

  3. Filtrado inteligente de mínimos:

    regiones_cercanas = distancias_filtradas < DISTANCIA_UMBRAL
min_indices = [i for i in min_indices if regiones_cercanas[i]]
    • Solo consideramos mínimos que ocurren cuando el péndulo está cerca del sensor
    • Evita detecciones falsas de objetos en el fondo

  4. Visualización mejorada:

    • Señal cruda y filtrada superpuestas
    • Líneas de referencia para el umbral y período teórico
    • Región sombreada que muestra la desviación estándar

  5. Manejo robusto de errores:

    • Verificación de suficientes datos
    • Captura de excepciones
    • Mensajes de error descriptivos

2.4.14 Parámetros Ajustables Clave

  1. DISTANCIA_UMBRAL:
    • Distancia máxima para considerar “detección válida”
    • Debe ajustarse según la distancia sensor-péndulo en reposo
  2. Parámetros de find_peaks:
    • distance: Mínimo muestras entre picos (ajustar según velocidad péndulo)
    • prominence: Importancia mínima del pico (reduce falsos positivos)
    • width: Ancho mínimo del pico
  3. TIEMPO_ADQUISICION:
    • Duración de la medición en segundos
    • Para 10 oscilaciones típicas: ~20-30 segundos
